CYCLE STUDIO / TEST EVALUATION

試験とサイクルを、同じ条件で比較する

原データ・計測定義・計算条件を残し、差の理由を調べるための評価ノート。

サイクル計算軸締結強度操作マニュアル ↗
設計点モデルとの比較です。性能マップによるオフデザイン解析や規格に基づく受入試験判定は行いません。定常性・測定位置・校正データとの独立性は利用者が確認してください。

01 / 評価と基準モデル

基準サイクルの入力JSON（効率・損失・段構成など）

02 / CSVと定常区間

UTF-8 CSV（ファイル選択は200KBまで）。先頭行は列名、時刻は試験開始からの秒数（昇順）。空欄・非数値は欠損として集計します。

原CSVを表示・貼り付け

各項目は有効な値の算術平均です。欠損数・標準偏差・最小最大・時間傾向を結果で確認できます。自動で定常区間を選びません。

03 / 計測位置と用途

運転条件は計算入力に反映。校正用は参考差分。検証用は独立性の確認対象です。静圧・静温・相対全温を全圧・全温に読み替えないでください。
