カービック・スプラインの概略強度設計

矩形歯の片持ち梁・平均歯面圧・円環軸断面を使う静強度スクリーニングです。AGMA/Gleason規格の認証計算や3D接触応力ではありません。詳細な式・定義・境界・入出力契約は配布ファイルSHAFT_JOINTS.mdに記載しています。

サンプル操作

  1. 初期スプラインは500 N m、使用係数1.5、24歯、分担歯割合0.5、有効長30 mmです。平均歯面圧41.6667 MPa、部材A歯元曲げ83.3333 MPa、必要長12.5 mm、許容公称トルク1200 N mを確認します。
  2. 保存後、トルク1300 N mへ変更・再計算して超過と保存ケースとの差分を確認します。
  3. カービックに切替。外径100/内径70 mm、500 N m、組立締付80 kN、ばらつき0.1、緩和0.1、熱変化−5 kN。残存59.8 kN、保持基準による必要組立40.1258 kN、許容公称トルク636.6546 N mを確認します。
  4. 締付力を下げると保持が不足し、増やすと面圧・歯元圧縮・ボルト引張が増えます。全評価表を確認します。
  5. 保存・比較・結果JSON・評価表CSVを利用できます。取込JSONは入力だけを取り込み再計算します。

共通の力と安全率

Tnom = |T| または |P|/(2πN/60)
Td = 使用係数×Tnom
Ft = Td/r
ne = 歯数×荷重分担割合
Ft,tooth = Ft×歯幅方向係数/ne
歯元せん断 τ = Ft,tooth/(b t)
歯元曲げ σb = 6 Ft,tooth a/(b t²)
相当応力 = sqrt[(σb+|σaxial|)²+3τ²]
利用率 = 計算値×要求安全率/入力許容値

両部材の弱い側の許容値を、使用温度・材質・熱処理・寿命等の根拠とともに入力します。温度は記録値で、自動的な材料強度補正はしません。使用係数は軸力・曲げにも適用。荷重0の安全率は未定義として表示します。

スプライン

平均歯面圧 = Ft×歯幅方向係数/(ne L h投影)
歯面半径力の絶対値和 = Ft tan α
等価ハブ内圧 pi = Σ|Fr|/(π dhub,inner L)
ハブ周応力 = pi (Ro²+Ri²)/(Ro²−Ri²)

hは半径方向投影歯丈です。平均面圧であってHertz応力ではありません。ハブは厚肉円筒Lamé式の等価評価で、局所歯底・しまりばめ・残留・遠心応力は含みません。歯部・ハブの必要長さを表示しますが、軸断面超過は長さだけでは解消しません。直歯スプライン自体の軸保持力は評価しません。

カービック

r = (Do+Di)/4、b = (Do−Di)/2
α = 歯面法線の接線面からの角度
Fsep = Ft tan α + 軸方向分離力 + M A ro/I
Pmin = max[0,P0(1−ばらつき)(1−緩和)+熱変化]
Pmax = max[0,P0(1+ばらつき)+熱変化]
要求残存締付力 = 締付倍率×Fsep
必要組立締付力 = max[0,(要求残存締付力−熱変化)/((1−ばらつき)(1−緩和))]
Nloaded = [(Pmax+M A ro/I)/sinα + Ft/cosα]/2
平均歯面圧 = Nloaded×歯幅方向係数/(ne b h実歯面)
ボルト群平均引張 = (Pmax+Cbolt Fsep)/合計有効引張面積

歯面の曲率・接触斑点を解かない対称くさび近似です。Hirthの角度・寸法を流用しません。円環の最小等価圧力や除荷側歯面の離間を確認します。離間時は歯部応力を参考値として扱います。必要組立締付力は保持だけの下限で、歯部・ボルト強度の成立も必要です。

軸断面とトルクの位置

中実/中空円断面のねじり・曲げ・軸力を、入力した静的応力集中係数とともにvon Misesで合成。カービックでは保守側に最大締付圧縮も加えます。保存サイクルの取出し軸・圧縮機伝達部・タービン機械伝達後の分岐前から、軸位置を選んで動力と回転数を取り込みます。電気出力をそのまま軸動力として扱いません。実際の分岐・補機・ポンピング荷重経路は別途確認してください。

保存と未評価項目

軸締結の保存先は専用cases.shaft-joints.sqlite3です。サイクル・設計情報管理ケースを上書きしません。入力contextには案件・部品IDを保持できます。歯元フィレット、深い梁、曲面接触、歯当たり、フレッティング、疲労、クリープ、回転遠心応力、熱応力、ボルト配置別の局所応力、規格公差適合は未評価です。

理論上の参照と範囲

NASA SP-8101 §§3.3.1–3.3.2は荷重分担、カービック保持力、詳細応力検討の指針です。AGMA 945-1-B20の公式スコープには圧縮・せん断・曲げ・周応力等を含みます。本文の有料式を実装したものではありません。今回の力の釣合い・矩形梁・円環・Laméの組合せは独自の概略モデルです。
