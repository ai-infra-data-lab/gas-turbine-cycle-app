# Secondary Air Network 0.5

ガスタービンの二次空気系を、完全混合室と流路のネットワークとして計算するローカルアプリです。第1段階の定常・圧縮性・比熱一定モデルを実装しています。Python 3.10以上の標準ライブラリだけで動作します。インターネット接続、アカウント、追加パッケージは不要です。

v0.2では、歯ごとに圧力を解くラビリンス基礎モデル、隙間・歯数の感度解析、強制渦／自由渦の独立した圧力分布計算を追加しました。[STAGE2.md](STAGE2.md) に式・操作・限界を記載しています。

v0.3では、**同一回転系の断熱流路をネットワークへ連成**しました。回転する境界／混合室の半径・rpm、相対全温と絶対全温、軸動力・トルク・ロタルピー残差を扱います。「回転流路サンプル」で実行できます。[STAGE2B.md](STAGE2B.md) に定義・式・適用範囲・数値例を記載しています。静止系との直接接続や任意スワールは未対応です。

v0.4では、**基準・2倍・4倍の分割数依存性チェック**を追加しました。全流路・全ノードの数値変化と状態切替を比較し、3段階の入力・結果を検証JSONに出力します。画面の「分割数チェック」から実行できます。[GRID_STUDY.md](GRID_STUDY.md) に比較式・許容値・CLI・限界を記載しています。

v0.5では、上限を**200ノード・500流路**に拡張しました。「ノードを検索」「流路を検索」でIDや名称を絞り込めます。流路は接続ノードでも検索できます。25ノードまたは60流路を超えるケースを読み込むと接続図は初期状態で折り畳まれます。接続図の行を選ぶと展開し、縦横にスクロールできます。

圧力反復では、質量残差がエネルギー収支に与える影響も考慮して許容値を決めます。定常計算で圧力または温度の収支が未収束の場合は、「計算結果」の収束診断に対象ノードの名称・ID・残差・許容値・超過量が表示されます。[収束判定の式](THEORY.md#6-ソルバー)

## 起動

`start.bat` をダブルクリックしてください。ブラウザで <http://127.0.0.1:8790/> を開きます。

```powershell
cd C:\Codex\pythonのGUI作成\secondary_air_network
python server.py --open
```

終了は起動ウィンドウでCtrl+C。別ポートは `python server.py --port 8791 --open`。

既存の設計情報管理・サイクル計算などのアプリから独立しています。保存先はこのフォルダの `data/cases.sqlite3`。既存アプリのDBは使用しません。

Cycle Studioの「設計アプリ連携 → 二次空気・サイクルへの反映」で、圧縮機段の抽気とタービン動翼前後縁の背圧を取り込めます。静止系は冷却枝の流量・全温と返却用サイクルケース、回転系は周速と一致する予旋回を与え、ラビリンスの漏れと軸仕事を取得できます。[連携手順](../DESIGN_TOOLS.md)

## 最初の操作

1. 起動時の「架空サンプル」を使うか、「新規」で供給・排出境界と計量孔から始めます。
2. ノード表で圧力境界の絶対圧力[kPa]・全温[K]を入力します。内部混合室の圧力・温度は初期値で、計算で決まります。
3. 流路を選択し、接続・面積[mm²]・係数を編集します。配管では水力直径[mm]、長さ[m]、粗さ[mm]、K、壁温・熱伝達率などを入力できます。
4. 「定常計算を実行」。圧力・混合全温・流量・逆流・チョーク・熱収支を確認します。モデルの注記も表示します。
5. 「ケース保存」で入力と計算結果を新しいスナップショットとして保存します。「保存・比較」では2ケースをIDで対応付けて比較できます。過去のケースは上書きしません。
6. 「感度解析」では対象と項目を選び、SI単位で開始・終了・点数を指定します。各点を独立に再計算し、未成立点は理由を表示します。

7. 「分割数チェック」で48→96→192などの数値変化を確認します。対象流路の基準分割数は64以下。比較許容値内は実機精度の保証ではありません。

入力変更後は結果・保存・結果出力・分割検証レポートを無効化します。編集途中の自動保存はありません。入力JSONは有効なモデルなら未計算でも書き出せます。

## 計算できるもの

- 圧力・温度境界と内部混合室。複数の抽気源、分岐、合流、ループを持つ抵抗ネットワーク。
- 圧縮性オリフィスと、校正用のCdA等価漏れ。順逆方向のCdを指定。
- 一定断面配管：密度変化、Darcy摩擦、局所抵抗、壁面熱交換、指定熱入力、亜音速流、チョーク。
- 長さゼロの等価局所抵抗。順逆方向のKを指定。
- 各混合室の指定熱入力と全エンタルピー混合。
- R・γの入力（cp=γR/(γ−1)）、Sutherland粘度、円管の層流摩擦とHaaland乱流摩擦。
- 保存・読込・比較、入力/結果JSON、結果CSV、1変数感度解析（2～15点）。

## 適用範囲

静止ノードは速度ゼロの完全混合室で、静圧=全圧、温度は混合全温です。回転ノードは**相対速度ゼロ**で、入力は静圧=相対全圧と相対全温です。絶対系では接線速度U=Ωrを持ちます。相対量を静止系へそのまま渡さないよう、異なる座標系・rpmの接続を拒否します。通常流路は同じ半径で使い、半径変更には断熱回転流路を使います。

静止流路入口は貯気槽から等エントロピー加速し、流路出口の静圧を下流混合室に合わせます。出口噴流は混合室で散逸します。回転流路は、絶対全エンタルピーと回転仕事を含めて保存則を評価します。熱による自励流・浮力・汎用の圧力回復機器は扱いません。

配管は区間ごとに質量・運動量・全エンタルピーを計算します。既定48分割。Kを全区間に均等配分する等価モデルなので、高速の急拡大や急縮小などの詳細損失を予測するモデルではありません。高マッハ・強い加熱では96/192分割との比較が必要です。

以下は次段階です：静止系／回転系の移送要素、任意スワール、回転キャビティのトルク・風損・熱連成、ラビリンスの持越し・歯形・ハニカム補正、プリスワール、回転孔、温度依存cp、実在気体、指定流量境界、過渡、固体熱伝導、熱変形からの隙間予測、翼温・寿命、リムシール侵入。等価漏れは従来どおり校正した絞りです。実機や市販ソフトとの数値一致は未検証です。

入力範囲は200ノード・500流路、分割8～256、1 kPa～50 MPa、全温150～2500 Kです。計算時間と収束は、回路の接続、配管の分割数、ラビリンス歯数、熱入力と初期条件で変わります。比熱一定・低密度気体の近似を使用します。係数には根拠と出典を入力してください。

## モデルファイルとCLI

サンプルは `examples/sample_network.json`。すべて説明用の仮定値です。JSONはSI単位（Pa、K、m、m²、W）。画面では一部をkPa・mm・mm²に換算します。

```powershell
python cli.py --input examples/sample_network.json --output result.json
```

CLIは失敗時に終了コード2となり、出力ファイルを書きません。結果JSONには正規化した入力モデルと計算結果・残差・注記を含めます。画面のJSON取込は64 MiBまでで、入力と、入力を内包する計算結果を選べます。取込後は再計算します。二次空気アプリのAPIには32 MiBまでの入力JSONを送信できます。

係数の定義・式・一次資料リンクはアプリ内「操作・計算モデル」と [THEORY.md](THEORY.md) を参照してください。

## 構成

`model.py` は入力検証、`engine.py` はネットワーク計算、`rotating.py` は同一回転系の流路、`seals.py` はラビリンス、`vortex.py` は独立した渦分布計算、`storage.py` は保存、`server.py` はローカルAPI、`static/` は画面です。計算部はHTTPやDBに依存しません。ソースと入力はUTF-8です。
