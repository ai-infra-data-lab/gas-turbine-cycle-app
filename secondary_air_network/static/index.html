DISCRETIZATION CHECK

配管・回転流路・局所抵抗の分割数を基準・2倍・4倍として、全ネットワークを独立に再計算します。対象流路の基準分割数は64以下にしてください。境界条件・形状・係数は同じ値を使用します。

2倍→4倍の差 ≤ max（絶対下限, 相対許容値×両者の絶対値の最大）を比較します。絶対下限: 流量1e−8 kg/s、圧力1 Pa、温度0.01 K、熱・軸動力0.01 W、M 1e−4。これは比較用の設定で、ソルバーの収束許容値とは異なります。

METHOD & VALIDATION

操作・計算モデル

最初の操作

  1. 「サンプル」で架空の抽気・冷却・シール分配を読み込みます。
  2. 境界ノードに絶対圧力[kPa]と全温[K]を指定します。混合室の圧力・温度は初期値で、計算で決まります。
  3. 流路の行を選び、面積、Cd、長さ、Darcy摩擦係数、壁温などを編集します。出典メモも記録してください。
  4. 「定常計算を実行」で結果・残差・適用上の注記を確認します。
  5. 案件名を変えてケース保存し、「保存・比較」で2案を比較します。入力変更後の結果は失効し、再計算が必要です。

状態量と係数

ノードは速度ゼロの完全混合室です。静圧=全圧、温度は混合後の全温です。圧力は絶対圧。すべての流路は両方向に流れ、逆流では反対側の境界温度と逆方向Cd/Kを使います。主流側の高温は、そこから逆流する場合だけ流入条件になります。

オリフィスは貯気槽からの圧縮性流れをCdで補正します。等価漏れは同じ式で、ラビリンス歯形や回転の効果を自動予測しません。Cdの基準面積は入力面積です。

配管の式

一定断面の亜音速1D流を分割します。質量流束G=ρV=ṁ/A、p=ρRT、h₀=cpT+V²/2。

p₂ − p₁ + G(V₂ − V₁) + (fD Δx/Dh + K/N) G(V₁+V₂)/4 = 0
ṁ cp(T₀₂ − T₀₁) = Qcell
Qwall = h Aw (Tw − Tstatic)  （各区間の指数積分）

入口は等エントロピーで加速し、出口の静圧を下流混合室に合わせます。音速限界に達するとチョーク流量になります。出口の運動エネルギーは混合室で散逸し、全エンタルピーは保持します。局所抵抗は長さゼロ・熱入力ゼロで、同じ運動量式にKだけを指定した等価モデルです。Kは全区間に均等配分するため、高速の急縮小・急拡大の詳細モデルではありません。

壁面積は4A L/Dh。壁面熱交換では区間入口の運動エネルギーを用いて全温と静温を変換します。指定熱入力は各区間に均等配分します。高マッハ・強い加熱では分割数48→96→192などで結果の変化を確認してください。

自動摩擦は円管層流64/Re、乱流Haaland、Re=2300～4000は線形補間。粘度は空気のSutherland式。粗さは等価砂粒粗さです。fDはDarcy係数（Fanning係数の4倍）。非円形の層流は固有の係数が必要で、固定摩擦の指定を推奨します。

熱・収束

混合室では流入・流出の質量流量と、入熱を含む絶対全エンタルピーの収支を合わせます。圧力を減衰Newton法で解き、温度と反復します。内部ノードごとの質量残差1e−9+1e−7×流量[kg/s]と、熱残差1e−5+1e−7×エンタルピー流量[W]を基準にし、質量残差によるエネルギー誤差を熱許容値の半分以内に抑えます。境界の収支差は外部への供給・排出です。圧力・温度反復が止まったときは、「計算結果」の収束診断で許容値を超えたノードを確認できます。

流れのない混合室の温度は不定として表示します。温度範囲は150～2500 K、圧力は1 kPa～50 MPa。比熱一定の誤差は温度範囲が広いほど大きくなります。回転、浮力、超音速、衝撃波、固体熱伝導、熱変形、リムシール侵入、翼温・寿命は評価しません。実機設計合否の自動判定は行いません。

第2段階A：ラビリンスと渦の補助計算

「シールサンプル」は4歯の架空値です。ラビリンスでは隙間の平均径Dmと半径隙間cから各歯の面積A=πDm cを算出し、共通流量を満たす歯間圧力を計算します。各歯は圧縮性環状絞りで、歯間の軸方向運動エネルギーは完全散逸します。順逆方向Cdは各歯共通の校正値。個別隙間は正方向の歯番号順に指定し、逆流では逆順に評価します。中間歯でチョークする個別隙間のケースは、下流膨張が未対応のため未成立と表示します。歯先幅・ピッチ・ハニカム・持越し・回転風損の相関は含みません。Vermes法の実装ではありません。

隙間の感度解析はSI単位[m]です。例えば0.1～0.2 mmは0.0001～0.0002 m。個別隙間を入力している場合、全歯共通隙間の掃引は使用できません。

dp/dr = ρ Vθ²/r ; p=ρRT（静温Tを固定）
強制渦: Vθ=βΩr ; ln(p/pref)=β²Ω²(r²−rref²)/(2RT)
自由渦: C=βΩrref² ; Vθ=C/r ; ln(p/pref)=C²(1/rref²−1/r²)/(2RT)

渦の全温はT0=T+Vθ²/(2cp)。圧力比は回転方向の符号によらず、速度は符号を保持します。これは流量・トルク・回転仕事・必要熱量を計算するモデルではありません。完全混合室ネットワークとの熱力学的な接続は次段階です。

第2段階B：同一回転系の断熱流路

「回転流路サンプル」では、回転する供給境界→半径流路→外周混合室→同じ半径の冷却孔を連成計算します。ノードの静圧は相対全圧と等しく、入力温度は相対全温（相対速度ゼロなので静温と等しい）です。絶対全温・絶対全圧は結果表で別に表示します。境界値は回転系の量として指定する必要があります。

U=Ωr ; I=cp T0,rel − U²/2
T0,rel,out − T0,rel,in = (Uout²−Uin²)/(2cp)
T0,abs = T0,rel + U²/(2cp) （混合室）
Wshaft = ṁ (Uout²−Uin²) ; τ=Wshaft/Ω
Σṁ h0,abs,in − Σṁ h0,abs,out + Q + Wshaft = 0

回転系での遠心ポテンシャルの等エントロピー変化と、Darcy摩擦による圧力低下を分割して解きます。相対全温の上昇をすべて軸仕事とする扱いはせず、絶対系の運動エネルギーも収支に含めます。正の仕事は流体への入力、内向き流れでは負の仕事になり得ます。半径が同じなら回転による仕事差は0です。

同じ接続系は全ノードが同じ回転数・完全追従に限定します。半径を変える枝は「断熱回転流路」で接続し、通常の配管・孔・シールは同じ半径で使います。静止系との直接接続、異なる回転数、任意スワール、回転流路の加熱は拒否します。摩擦の回転補正・風損・スリップは未計算。高マッハや大きな遠心力では分割数48→96→192の感度を確認してください。

「感度解析」の対象「回転系」を選ぶと、その接続系の全ノードのrpmを同時に変更します。各点の境界相対全温は入力値を維持します。単一ノードだけのrpm変更で、異なる回転数を誤って接続することを避けています。

分割数依存性チェック

「分割数チェック」は流路の基準・2倍・4倍で全ネットワークを独立に解き、流量・圧力・温度・熱・軸動力・最大Mを比較します。対象の基準分割は64以下にしてください。2倍→4倍の差を明示した絶対下限・相対許容値で比較し、振動・変化増大・チョーク・流向切替を要確認として表示します。未成立段階も理由を残します。入力と保存ケースは変更せず、3段階の全入力・結果をレポートJSONに出力します。入力・比較許容値を変更するとレポートは失効します。比較許容値内は実機精度の保証ではなく、GCIや真の誤差帯は計算しません。NASAの段階的分割検証の説明を参照してください。

理論の出典

  • NASA Glenn — Mass Flow Choking：圧縮性絞りの理想流量と音速限界。
  • NPTEL — Fanno Flow：一定断面の摩擦流れ。配管の検証基準。
  • NASA GFSSP：ノードの質量・エネルギー、枝の運動量という構成。
  • Flow Simulator — Tooth by Tooth Seal：歯ごとに解く構成と未実装補正項の参考。
  • Flow Simulator — Vortex Elements：渦の圧力・温度・座標系の参考。商用モデルの再現や精度保証ではありません。
