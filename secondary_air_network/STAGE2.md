# 第2段階A：ラビリンス基礎モデル・渦圧力分布

## ラビリンス

「シールサンプル」→「定常計算を実行」。結果画面に各歯の隙間、上流・下流混合圧、歯先静圧、流量、Mach、チョークを表示する。平均径Dmは隙間の内外径の平均、cは半径隙間、各歯のA=πDm c。均一な歯を基本とし、任意で歯数と同数の個別隙間を正方向の順に指定できる。逆流時には歯番号順とCdを切り替える。

各歯にNASAの圧縮性流量関数を適用し、共通流量を満たす歯間圧力を求める。歯間の軸方向運動エネルギーは完全散逸し、断熱なので全温は一定。Cdは全歯共通・順逆別の校正係数。総面積や総Cdを歯数で割るモデルではない。

最終歯がチョークした場合、歯先静圧は臨界圧、下流混合室は指定背圧として区別する。個別隙間によって中間歯が先にチョークする場合は、下流膨張・混合が未実装のため未成立と表示する。

完全散逸の仮定は実際のラビリンスで成り立つとは限らない。歯先幅・ピッチ・歯形・ハニカム・持越し・回転風損からの係数予測は未実装。実機や市販ソフトとの照合前に、漏れ量の設計保証として使用しない。Vermes相関式の実装ではない。

構成参考：[Flow Simulator Tooth by Tooth Seal](https://help.altair.com/flowsim/topics/internal/solver_technical_manual/elements/elements_labyrinth_tbt_seal_internal.htm)。同資料では歯ごとの圧縮性流量関数、個別隙間、持越し・ハニカム・風損等の補正を区別している。本実装はこのうち完全散逸の基礎ケースに範囲を限定した独自実装。[NASAの理想流量式](https://www.grc.nasa.gov/www/k-12/BGP/mflchk.html) にユーザーCdを乗じる。

### 隙間感度

「感度解析」→対象「4歯ラビリンス」→「半径隙間[m]」。0.1～0.2 mmなら開始0.0001・終了0.0002。対象流路の漏れ量を総供給流量と別に表示する。個別隙間がある場合は共通隙間の掃引を拒否し、未使用のパラメータを変更して結果が変わったように見せない。歯数掃引は整数点のみ。

## 指定スワールの渦計算

「渦圧力分布」で、強制渦／自由渦、回転数、基準半径でのβ、基準静圧、静温、評価半径を指定する。軸対称・静温一定・半径方向加速度と粘性の影響を無視した静圧平衡。

dp/dr=ρVθ²/r, p=ρRT, Ω=rpm π/30。

強制渦：Vθ=βΩr。

ln(p/pref)=β²Ω²(r²−rref²)/(2RT)。

自由渦：C=βΩrref²、Vθ=C/r。

ln(p/pref)=C²(1/rref²−1/r²)/(2RT)。

絶対全温T0=T+Vθ²/(2cp)。回転方向の符号は速度に反映し、圧力は速度の二乗で決まる。Ω=0またはβ=0では圧力一定。自由渦ではβは基準半径の値であり、全半径で一定ではない。

モデル参考：[Flow Simulator Vortex Elements](https://help.altair.com/flowsim/topics/internal/solver_technical_manual/elements/elements_vortexes_internal.htm)。本計算は静圧分布の解析積分であり、同ソフトの温度・流量・回転仕事モデルを再現しない。

**渦の結果はネットワークに直接接続しない。** 既存ノードは速度ゼロで静圧=全圧だが、渦には接線速度があり全圧・全温が異なる。圧力上昇だけを枝に挿入するとエネルギーが不整合になる。流量、トルク、回転仕事、必要熱量、風損は未計算。vortex_study設定はJSON・保存ケースに保持するが、ネットワークの解を変更しない。

## 架空例と検証

`examples/stage2_seal_network.json` を画面へ取り込むか、CLIで計算できる。

```powershell
python cli.py --input examples/stage2_seal_network.json --output result.json
python -m unittest -v test_engine.py test_stage2.py test_server.py
```

架空シール：Dm=120 mm、c=0.15 mm、4歯、各歯Cd=0.7。ネットワーク中の漏れは約0.0241297051 kg/s、全供給量約0.104891697 kg/s。最終歯はチョーク。形状・係数は仮定値で実機未校正。

架空渦：30000 rpm、β=0.5、基準半径80 mm、基準静圧300 kPa、静温600 K、外半径180 mmの強制渦。外半径静圧361.413615 kPa、静圧比1.20471205。静温を保つ必要熱量は計算していない。

検証は単歯とNASA流量式の一致、明示的な個別オリフィス＋混合室ネットワークとの一致、各歯の流量一致、歯数・隙間感度、チョークと逆流、半径平衡の解析解・微分式、ゼロ回転、回転数二乗依存、保存・API。詳細は [VERIFICATION.md](VERIFICATION.md) のv0.2追記を参照。
