# 計算モデルと一次資料

以下1～7節は静止系の基礎モデル。v0.2のシール・等温渦は [STAGE2.md](STAGE2.md)、v0.3の同一回転系ネットワークは [STAGE2B.md](STAGE2B.md) を参照。回転系の入力温度は相対全温で、全体のエネルギー収支には絶対全エンタルピーと軸仕事を用いる。

## 1. ノード

すべて完全混合プレナム、速度ゼロ。p=p0、T=T0。内部ノードで質量とエネルギーを保存する。

Σṁin − Σṁout = 0

Σṁin cpT0,in − Σṁout cpTnode + Qnode = 0

単一の理想気体・比熱一定：cp=γR/(γ−1)。圧力温度境界は外部リザーバーであり、その収支差は供給・排出として集計する。流入のない内部ノードの温度は不定（null）。そこに熱入力がある場合は定常解なし。

構成参考：[NASA GFSSP](https://www.nasa.gov/gfssp/)。ノードで質量・エネルギー、枝で運動量を扱う。本実装は独自の小規模ソルバーで、GFSSPのコードや精度を再現したものではない。

## 2. オリフィス・等価漏れ

π=pd/p0u、π*=(2/(γ+1))^(γ/(γ−1))、x=max(π,π*)。

ṁ=Cd A p0u / sqrt(R T0u) × sqrt[2γ/(γ−1) × (x^(2/γ)−x^((γ+1)/γ))]

π≤π*でチョーク。Cdは入力面積に対する実流量／理想流量。下流は静圧、上流は全圧。逆流時は上流ノードとCdを切り替える。Cdは形状・Re・回転・クロスフローから自動推定しない。等価漏れはこの式を校正して使うための別名称。

一次資料：[NASA Glenn — Mass Flow Choking](https://www.grc.nasa.gov/www/k-12/BGP/mflchk.html)。NASAの理想式にユーザー入力Cdを乗じる。

## 3. 配管・局所抵抗

一定断面でG=ṁ/A=ρV。入口を全圧p0u・全温T0uから亜音速等エントロピー加速で求める。M≤1の流量関数を解く。

区間の運動量：

p2−p1 + G(V2−V1) + kcell G(V1+V2)/4 = 0

kcell=fD Δx/Dh + K/N

状態式と全エンタルピー：

p=GRT/V、T=T0−V²/(2cp)

全温T02を与えた区間運動量式は、V2について二次式になる。

a=1−R/(2cp)+kcell/4

b=−p1/G−V1+kcell V1/4

c=R T02

a V2²+b V2+c=0

亜音速側の小さい根を安定な形 V2=2c/(−b+sqrt(b²−4ac)) で選択する。実根がないかM≥1ならその試行流量は通過不能。流量を二分して、出口静圧=下流静圧、または音速の上限を求める。チョーク時の出口静圧は背圧以上となり、出口圧力不一致を未収束としては扱わない。超音速噴流や衝撃波は解かない。

長さ0の局所抵抗はKだけを同じ式に配分する等価モデル。損失Kを特定位置に置いた急拡大・急縮小の厳密な再現ではない。

検証基準：[NPTEL — Fanno flowの運動量式](https://archive.nptel.ac.in/content/storage2/courses/112103021/module2/lec15/1.html)、[Fanno flowの解析](https://archive.nptel.ac.in/content/storage2/courses/112103021/module2/lec17/1.html)。断熱・固定摩擦では次式と比較する（fDはDarcy係数）。

F(M)=(1−M²)/(γM²)+(γ+1)/(2γ) ln[(γ+1)M²/(2+(γ−1)M²)]

fD L/Dh = F(M1)−F(M2)

## 4. 摩擦と粘度

Re=G Dh/μ。自動摩擦は円管の十分発達した層流でfD=64/Re（Re≤2300）。Re≥4000でHaaland。

1/sqrt(fD)=−1.8 log10[(ε/(3.7Dh))^1.11+6.9/Re]

2300<Re<4000は層流式と乱流式の線形補間で、遷移の物理を予測する相関式ではない。非円形の層流には固有係数が必要。摩擦係数を直接指定する場合もDarcy。fD=4 fFanning。粗さεは等価砂粒粗さ。

Haaland, S. E. (1983), “Simple and Explicit Formulas for the Friction Factor in Turbulent Pipe Flow”, Journal of Fluids Engineering 105(1), 89–90, [DOI:10.1115/1.3240948](https://doi.org/10.1115/1.3240948)。

空気粘度：μ=1.716e−5 (T/273.15)^1.5 (273.15+110.4)/(T+110.4) [Pa·s]。組成・圧力依存性は扱わない。出典：[NASA Scientific Ballooning Handbook, Dynamic Viscosity](https://ntrs.nasa.gov/api/citations/20240004989/downloads/50th%20Anniversary%20Ed%20Scientific%20Ballooning%20Handbook.pdf?attachment=true)。高圧に入力できることは、Sutherland式や理想気体近似の高圧精度保証を意味しない。

## 5. 壁面熱交換・熱入力

区間でṁ cp ΔT0=Qcell。壁面積Aw=4A Δx/Dh。hはユーザー入力。x=hAw/(ṁcp)、Teq=Tw+V1²/(2cp) として、

T02 = T01 + (Teq−T01)(1−exp(−x)) + (Qspecified/N)/(ṁcp) × (1−exp(−x))/x

h=0の極限では最後の係数を1とする。区間入口の運動エネルギーを固定して熱交換を指数積分し、その後に運動量式を解く分割近似。強い加熱・高速では分割数依存性を確認する。固定熱入力はN分割し、対流と同時に加える。空気の全温、静温、壁温を混同しない。

同じ温度の壁でも静温と全温が異なる場合は熱交換が生じる。断熱では全温が保存され、出口混合時も全エンタルピーを保持する。

## 6. ソルバー

各枝の流量を内部圧力で評価し、内部ノードの質量残差を減衰Newton法で解く。Jacobianは各枝の端点圧力による差分から構成。小規模密行列・部分ピボット法。指定枝熱入力がある場合は断熱の圧力場から開始する。温度は流入エンタルピーと熱入力から更新し、圧力と連成反復する。

質量収束の基準値は εm = 1e−9 + 1e−7 max(ṁin,i,ṁout,i) [kg/s]。

エネルギー収束は |Renergy,i| ≤ εE、ここで εE = 1e−5 + 1e−7 cp Ti max(ṁin,i,ṁout,i) [W]。

流入エンタルピーから温度が定まった後も、質量残差 Rmass,i があると絶対全エンタルピー h₀,i = cp Ti + U²/2 を掛けた分だけエネルギー残差が残る。圧力反復の許容値を min(εm, 0.5 εE / h₀,i) として、この寄与をエネルギー許容値の半分以内に抑える。U は回転する混合室の周速で、静止系ではゼロ。

圧力反復45回、熱連成100回を上限とし、最後の更新後の収支まで評価する。収支が許容値を超えたまま温度更新量が全ノードでゼロになった場合は停滞として終了する。圧力・温度反復の未収束時は、対象の収支を超過したノードの符号付き残差と許容値を返す。画面では超過量も示す。入力変更後の旧結果は画面から保存・出力できない。保存APIも入力を再計算してから記録する。
