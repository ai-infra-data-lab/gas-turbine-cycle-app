# v0.3：同一回転系の流路ネットワーク連成

## 操作

1. 「回転流路サンプル」→「定常計算を実行」。3つの回転ノードと断熱回転流路・冷却孔を解く。全数値は架空の仮定。
2. ノードの回転数[rpm]・半径[mm]を確認する。**回転系の入力温度は相対全温**。圧力は静圧=相対全圧。静止系の全圧・全温をそのまま入力しない。
3. 結果表で静圧、各系全温、絶対全温・全圧、軸動力、トルク、ロタルピー残差を確認する。軸動力の正は流体への入力、負は回収。
4. 感度解析の対象「回転系 / 回転系供給境界」でrpmを選ぶ。接続する全ノードのrpmを同時に変更する。例：開始0、終了30000、3点。境界の相対全温は入力値を維持するので、実機のオフデザイン解析を自動再現するものではない。
5. ケース保存・読込・比較、JSONとCSV出力に対応。旧ケースは静止系として読み、DBの自動書換はしない。

`examples/rotating_network.json` を入力してCLIでも実行できる。

```powershell
python cli.py --input examples/rotating_network.json --output result.json
python verify_rotating.py
```

## 状態量と保存則

流体がロータに完全追従し、相対接線速度が0の流路。回転混合室では相対速度全体が0。U=Ωr、Ω=rpm π/30。

I = h + w²/2 − U²/2 = cp T0,rel − U²/2

断熱流路ではIを保持するモデルなので、

cp(T0,rel,out−T0,rel,in) = (Uout²−Uin²)/2。

相対速度ゼロのノードの絶対全温：

T0,abs=T0,rel+U²/(2cp)。

静圧は座標系によらずp。相対速度ゼロなのでp0,rel=p。絶対全圧は同じ局所状態を絶対系で等エントロピー減速した定義として、

p0,abs=p (T0,abs/Tstatic)^(γ/(γ−1))。

流体の角運動量変化と軸動力：

τ=ṁΩ(rout²−rin²)、Wshaft=Ωτ=ṁ(Uout²−Uin²)。

**相対全温の上昇だけを使うと絶対系の仕事の半分になる。** 本実装では接線運動エネルギーも含め、絶対全エンタルピーの変化と回転仕事を整合させる。混合室の収支と全体の収支も絶対量で評価する。

Σṁin h0,abs,in − Σṁout h0,abs,out + Q + Wshaft = 0。

回転数は外部駆動で指定し、必要な軸動力を求める。供給可能な動力、軸の加減速、他の回転機器との機械的連成は扱わない。

## 流路の数値モデル

一定断面、半径が入口から出口へ線形に変化する流路を分割する。長さは両端の半径差以上に制限する。各区間では次を順に計算する。

1. 遠心ポテンシャルΔΦ=Ω²(r2²−r1²)/2により、T0,rel,2=T0,rel,1+ΔΦ/cp。
2. 摩擦なしのポテンシャル変化は等エントロピーとし、p0,rel,2=p0,rel,1(T0,rel,2/T0,rel,1)^(γ/(γ−1))。固定流量に対応する亜音速状態を求める。
3. 同じT0,relでDarcy摩擦・Kの圧力低下を従来の1D運動量式で計算。相対全エンタルピーは保持する。
4. 下流の静圧に一致する流量、または流路入口／出口の音速限界を二分法で求める。

ポテンシャルと摩擦の演算分割による誤差があるため、48→96→192分割で確認する。摩擦なしでは半径変化の等エントロピー解析解、rpm=0では従来の配管、同一半径では仕事差0へ戻る。

流向は、入口状態から求めた断熱・等エントロピーの回転平衡圧と下流圧を比較して両方向を評価する。境界温度によって両方向の駆動条件が競合したり、流向を一意に決められない場合は未成立とする。温度条件の曖昧さをゼロ流量の収束として扱わない。内部回転ノードの初期温度は、同じ接続系の最初の回転境界から一定Iの値で初期化し、以後は混合収支で更新する。

## 入力の制限

- 同一接続系は同一rpm・同一座標系。通常の配管・オリフィス・シールは同一半径で使用する。
- 半径の変更はrotating_pipeだけ。半径1 mm以上。ノードの最大絶対全温2500 K、圧力1 kPa～50 MPa。
- rotating_pipeは断熱。壁面加熱は未対応。混合室への熱入力は別に保存則へ加える。
- スリップ、任意β、プリスワール、ロータ／ステータ間移送、異なるrpmの接続は未実装。静止系との直結を拒否する。
- 自動摩擦は静止円管の近似。回転に伴う摩擦係数や熱伝達率の変化、風損は未予測。相関式を校正してから使用する。
- 独立した「渦圧力分布」はv0.2の等温・指定βの補助計算であり、この断熱・完全追従流路とは別モデル。

## 数値例・検証

30000 rpm、内半径80 mm、外半径180 mm、入口静圧400 kPa・相対全温550 K、外周の排出境界300 kPa。流路A=200 mm²、長さ0.2 m、固定fD=0.02、K=0.3、冷却孔A=80 mm²・Cd=0.7（すべて仮定）。

| 項目 | 48分割の計算結果 |
|---|---:|
| 流量 | 0.0694033875 kg/s |
| 外周混合室の静圧 | 798.311503 kPa |
| 入口相対全温 / 絶対全温 | 550 / 581.435772 K |
| 外周相対全温 / 絶対全温 | 677.707823 / 836.851418 K |
| 流体への軸動力 | 17809.5835 W |
| トルク | 5.66897 N·m |
| 全体エネルギー残差 | 約1.67e−5 W |
| ロタルピー残差 | 約1.37e−9 J/kg |

回転数0/15000/30000 rpmで流量約0.03268838/0.04331658/0.06940339 kg/s、軸動力0/2778.864/17809.583 W。48→192分割で流量は約0.0210%変化。これは数値例の分割依存性で、実機精度の保証ではない。

保存則、逆流時の負の仕事、回転方向反転とトルク、摩擦なし解析解、ゼロ回転極限、静止系との誤接続拒否、回転系一括掃引、保存互換を自動検証する。実機・市販ソフトとの照合は未実施。
