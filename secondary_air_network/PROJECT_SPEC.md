# Secondary Air Network — 第1段階 + 第2段階A・B + 数値検証

独立したローカルWebアプリ。既存の設計情報管理・サイクル計算・その他のアプリやDBを変更しない。

## 計算の範囲

- 定常、単一組成の空気、理想気体、比熱一定。Rとγを入力しcp=γR/(γ−1)。
- ノードは速度ゼロの完全混合室。圧力は静圧=全圧、温度は混合後の全温。
- 境界は圧力・温度指定、内部は圧力・温度を計算。各接続成分に圧力境界が必要。
- 枝は圧縮性オリフィス、校正した等価漏れ(CdA)、配管、局所抵抗。
- 配管は一定断面の亜音速1D流。質量・運動量・全エンタルピーを分割計算し、摩擦と伝熱、チョークを扱う。入口は貯気槽からの等エントロピー流入、出口は下流混合室の静圧に整合。出口噴流は混合室で散逸する。超音速・衝撃波・圧力回復ディフューザーは範囲外。
- 配管の摩擦はDarcy係数指定、または円管の64/Re・Haaland近似。遷移域は線形補間で警告。Sutherland粘度。非円形は断面積とDhを別に指定可能だが自動層流係数は円管近似。
- 配管は壁面熱伝達率と壁温、枝・ノードへの指定熱入力。低流量の加熱で定常解が成立しない場合は失敗を明示。
- 順方向・逆方向のCd/Kを入力。流向反転時は上流温度を切替。
- 圧力は減衰Newton法、温度は流入全エンタルピー混合との反復。収束しないものは成功として保存しない。

## 操作

ノード・枝の表編集、接続図、追加・削除、JSON取込/書出し、ローカルSQLiteケース保存・読込・比較、結果CSV、運転点ケース、1変数感度解析。入力変更時は結果を失効。係数ごとに出典メモを保持。サンプルは架空と明記。

## 境界・制限

127.0.0.1のみで起動、標準ライブラリのみ、外部CDN不要。25ノード・60枝以内、配管分割8〜256。回転キャビティ・専用ラビリンス・プリスワール・実在気体・温度依存cp・過渡・固体熱伝導・自動設計合否判定は次段階。

## 必要な検証

NASAオリフィス式、チョーク前後、逆流、対称分岐、熱混合、Fanno解析解、無摩擦加熱の運動量保存、分割数依存性、接続不良/不正入力/未収束、保存とAPI、ブラウザで一連操作。実機・市販ソフトとの一致は未検証とする。

## 第2段階A（v0.2）

- ラビリンス：一定平均径・1～30歯。各歯を圧縮性環状絞りとして、共通流量と歯間圧力を解く。面積はA=πDm c。歯間の軸方向運動エネルギーは完全散逸。Cdはユーザー校正値。共通／個別隙間、逆流時の歯順・Cd切替、最終歯チョーク、歯間状態表、隙間・歯数感度を実装。
- 中間歯のチョーク後の膨張、持越し、ハニカム、歯形からのCd予測、回転風損は未対応。Vermes法と称しない。
- 渦：指定スワール・静温一定の強制渦／自由渦の半径方向静圧平衡を独立計算。静圧・静温・絶対全温・接線速度・密度を表示。設定は任意のvortex_studyとして案件に保存するが、ネットワーク方程式には使用しない。
- 速度ゼロの既存ノードと、スワールを持つ状態の全圧・全温・回転仕事を整合させたネットワーク連成は第2段階Bへ分離する。圧力補正だけを既存の枝に追加しない。
- JSON schema_version=1と旧ケースを継続使用し、既存ケースの自動書換・移行は行わない。

## 第2段階B（v0.3）

- ノードにframe（stationary/rotating）、rpm、radius_mを追加。未指定の旧データは静止系・0 rpm。回転ノードはロータに完全追従し、相対速度ゼロ。入力pressure_paは静圧=相対全圧、temperature_kは相対全温=静温。絶対全圧・絶対全温は結果に別フィールドとして出力。
- rotating_pipeは同一回転数の回転ノード間の断熱流路。遠心ポテンシャルと摩擦を分割して流量・圧力・温度を計算。ロタルピーと、絶対全エンタルピー・回転仕事を含む収支を保持する。内向き逆流・入口/出口チョークを扱う。
- 回転数指定は外部の駆動条件。必要軸動力・トルクを計算するが、供給可能動力や軸の運動方程式は扱わない。相対全温の変化を、そのまま絶対系の仕事としない。
- 通常枝は同じ座標系・rpm・半径の間に限定。静止系／回転系の直結、異なるrpm、通常枝による半径変更、回転流路の加熱を拒否。任意スワール・ロータ/ステータ移送・風損は次段階。
- 回転ノードは通常の境界／内部混合室としてネットワークで解く。内部圧力を境界圧力の最大値に制限しない。熱収支は絶対全エンタルピーで評価。流向の駆動条件が不定／競合する温度境界は未成立として返す。
- 接続系の全ノードを同じrpmに変更する回転数感度、JSON/CSV、保存・比較、架空の回転流路サンプルを追加。温度依存物性や実機精度を保証しない。

## 数値検証（v0.4）

- 配管・回転流路・局所抵抗の分割を1/2/4倍として全ネットワークを独立再計算。基準は64以下、最大256。形状・係数・境界・歯数は保持。
- 全流路/全ノードの流量・圧力・各系/絶対全温・熱・軸動力・最大Mを比較。絶対下限と相対許容値を明示し、状態切替・振動・変化増大・不定値・未成立を区別する。比較許容値内を実機精度・設計合否と扱わない。
- 入力や既存DBは変更せず、3段階の全入力・結果を独立JSONレポートとして出力。UI/API/CLI対応。入力・比較条件変更時に古いレポートを無効化。GCIや外挿誤差帯は未実装。詳細はGRID_STUDY.md。

## 入力規模の拡張（v0.5）

- 現行上限は200ノード・500流路。旧版の入力形式と保存ケースを引き続き使用できる。
- 画面の件数表示と追加時の上限はモデル検証と同じ値を使用する。ノード・流路の検索は表示に適用し、回路データと計算対象の全件を保持する。
- 圧力方程式の消去で係数がゼロの行に対する更新を省略する。圧力・温度の計算式と収束許容値は従来どおり。
