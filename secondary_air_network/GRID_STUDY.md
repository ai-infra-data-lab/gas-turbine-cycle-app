# v0.4 分割数依存性チェック

## 操作

1. 案件を読み込み、「分割数チェック」を開く。計算前の入力でも実行可能。
2. 配管・回転流路・局所抵抗の基準分割数を8～64にする。上限256のため65以上は拒否し、自動切下げはしない。例：48 → 96 → 192。
3. 相対比較許容値[%]を指定して実行。既定0.1%、範囲0.000001～10%。これは設計基準やソルバーの反復収束基準ではなく、利用者が選ぶ比較条件。
4. 流路流量、ノード静圧、各系/絶対全温、出口全温、熱入力、軸動力、最大Mを切り替えて比較する。チョーク・流向の切替も別表に表示する。
5. 「検証レポートJSON」で3段階の全入力・結果・残差・注記を出力。入力値・比較許容値を編集するとレポートは失効する。入力の分割数と保存ケースは変更しない。

分割計算しないオリフィス・漏れ・ラビリンスは形状を変えないが、他の枝によるネットワークの変化は再計算する。ラビリンスの歯数は物理形状なので倍増しない。分割する流路がない案件は対象外。

## 比較の定義

基準/2倍/4倍の値をa,b,cとする。全段で圧力・温度・流量を独立に解き、前段の結果を次段の初期値に流用しない。

```
差 D = |c−b|
スケール S = max(|b|, |c|)
変化率 [%] = 100 D / S（S=0ではnull）
比較許容差 L = max(絶対下限, 相対比較許容値[%] / 100 × S)
D <= L なら、その量は「比較許容値内」
```

| 量 | 絶対下限（SI） |
|---|---:|
| 流路流量 | 1e−8 kg/s |
| ノード静圧 | 1 Pa |
| ノード全温・絶対全温、流路出口全温 | 0.01 K |
| 流路熱入力・軸動力 | 0.01 W |
| 最大マッハ数 | 1e−4 |

上記はこのアプリの明示的な比較設定。標準規格や商用ソフトの精度基準を称しない。ゼロ付近や符号を持つ仕事・流量にも同じ定義を使う。相対差が大きくても絶対下限より小さい変化は許容する。

全量を比較し、1つでも許容差を超えれば全体は「要確認」。a→bとb→cの差の符号が逆なら「振動」、後の絶対差が前の1.05倍より大きければ「変化量増大」。両差が絶対下限以下の微小変化を除き、これらは許容差内でも全体を「要確認」にする。増大判定の1.05は数値変動に対する実装上の余裕であり、物理的な精度基準ではない。

チョーク状態または流向が3段階の途中で変われば「要確認」。流向の分類は|ṁ|≤1e−8 kg/sを停滞とし、それ以外を正/逆とする。全段で不定の温度は比較対象外。一部だけ不定なら要確認。

いずれかの段階が未成立なら、他の段階も計算して理由を記録し、全体は「一部未成立」。数値比較による判定は行わない。各段階のソルバー注記・残差はレポートの`levels[].result`に保持する。

## API / CLI

`POST /api/grid-study` に `{"model": 入力モデル, "relative_percent": 0.1}`。既存APIと同じHost・Origin・トークン検証、1MB入力上限、計算ロックを使う。DBには書き込まない。

```powershell
python cli.py --input examples/rotating_network.json --output artifacts/grid_rotating.json --grid-study --relative-percent 0.1
```

入力不正は終了コード2で出力先を変更しない。一部未成立の場合は診断レポートを出力し、終了コード2。「要確認」は正常に比較を完了した結果なので終了コード0、`assessment`で判断する。レポートは独立した形式であり、通常ケースとして保存・入力JSONとして再取込する機能は設けていない。元のモデルはレポート内の`model`に残す。

## 確認例

架空の回転流路サンプル：

| 分割数 | 流量 kg/s | 軸動力 W |
|---:|---:|---:|
| 48 | 0.0694033875451 | 17809.5834583 |
| 96 | 0.0693936609976 | 17807.0875317 |
| 192 | 0.0693887899238 | 17805.8375669 |

96→192の流量変化約0.0070195%、軸動力差約1.24996 W。既定比較条件では比較許容値内。全体エネルギー残差は各段階で約4e−5 W以内。数値は現在の限定された物理モデルについての計算例。

## 意味と限界・一次資料

[NASA/NPARC — Examining Spatial (Grid) Convergence](https://www.grc.nasa.gov/www/wind/valid/tutorial/spatconv.html)では、段階的な細分化、反復誤差との区別、漸近領域、Richardson外挿・GCIの前提を説明している。本アプリはそのうち段階的細分化と量の比較を実装する。**2つの結果の差は真の離散化誤差の推定値ではない**。Richardson外挿、観測次数、GCI、連続体極限や誤差帯の推定は実装していない。

分割による変化が小さくても、比熱一定、完全追従、摩擦・Cd・熱伝達率、シール散逸などのモデル誤差は残る。実機データ・解析解・市販ソフトとの照合は別途必要。静止系／回転系の移送要素と風損は引き続き次段階。
